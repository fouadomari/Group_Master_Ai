A 30-day course for complete beginners · about 60 minutes a day

🐍 PyPath

From your very first line of Python to data science, machine learning, deep learning and language (NLP), one small step each day. You don't need to know how to code. Every new word is explained.

🧭 How it works

  • Each day is one page. Open it, read from top to bottom and press ▶ Run on the code boxes. Python runs right inside the page, so there's nothing to install.
  • Every day ends with exercises that check themselves, with hints if you get stuck.
  • Your answers are saved in this browser on this computer.
  • Each day also has a PDF to print, with an answer key at the end.

🌐 The first time you open a lesson it needs an internet connection to download Python (this takes a little while). After that your browser remembers it.
