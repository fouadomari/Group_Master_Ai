🤔 Why this matters

Welcome to the Data Science phase! Yesterday you added up expenses one by one with a loop. That's fine for ten numbers, but real data has thousands or millions of them.

NumPy (short for "Numerical Python") is a module that stores numbers in an array: a grid of numbers that all have the same type. Think of the difference between a cashier scanning items one at a time (a loop) and a machine that weighs the whole trolley at once (an array). NumPy does the whole-trolley maths, and it's very fast.

Almost every data science tool is built on NumPy: pandas tables (tomorrow!), charts, and machine learning models all keep their numbers in NumPy arrays.

📏 Summing up: aggregations

An aggregation squeezes many numbers into one: the total, the average, the biggest. Arrays have them built in. std is the standard deviation: roughly, how far the values typically are from the average (small = all similar, big = very spread out). argmax gives the position of the biggest value, not the value itself:

🗂️ 2D arrays: tables of numbers

A list of lists becomes a 2D array: rows and columns, like a spreadsheet. Here each row is a student and each column is a test:

Shift + Enter

Read scores[1, 2] as "row 1, column 2". A colon on its own means "everything", so scores[:, 0] is "all rows, column 0": the whole first column. Slices work too: scores[0:2, 1:3] would be rows 0–1 and columns 1–2.

Aggregations on a 2D array can work along an axis. axis=0 goes down the rows and gives one answer per column. axis=1 goes across the columns and gives one answer per row:

Shift + Enter

A trick to remember axes: the axis you name is the one that disappears. scores has shape (3, 4). axis=0 squeezes away the 3 rows and leaves 4 numbers; axis=1 squeezes away the 4 columns and leaves 3 numbers.

📡 Broadcasting: different shapes together

What happens with scores + 5? NumPy "stretches" the single number to match every element. This stretching is called broadcasting. It also works with a row: a list of 4 numbers is added to each row of a 3 × 4 table, so every column gets its own bonus:

Broadcasting only works when the shapes fit. Here is a mistake on purpose: 3 numbers and 2 numbers can't be paired up:

🎲 Random numbers with NumPy

NumPy can make whole arrays of random numbers, which is great for creating made-up data to practise on. First you make a random number generator with a seed (like random.seed(42) on Day 7), so the "random" numbers are the same every time:

Shift + Enter

rng.normal(170, 8, ...) draws numbers from the famous bell-shaped "normal" curve: most values land near 170, fewer far away. And note the last trick: the mean of a mask is the share (fraction) of True values. You'll use it a lot.

⚠️ Common mistakes

  • Forgetting import numpy as np → NameError: name 'np' is not defined.
  • Using and / or with arrays: use & / | and brackets around each comparison.
  • Mixing up the axes: axis=0 gives one result per column, axis=1 one per row.
  • Adding arrays whose shapes don't fit → "could not be broadcast". Check .shape.
  • Confusing argmax() (the position) with max() (the value).
  • Writing a loop when a single array operation would do.

✅ Recap

  • np.array(list) makes an array; it has a dtype, shape and ndim.
  • np.arange, np.linspace, np.zeros, np.ones create arrays.
  • Maths and comparisons work on every element at once.
  • A mask (arr > 5) filters: arr[arr > 5]; mask.sum() counts, mask.mean() gives the share.
  • sum, mean, min, max, std, argmax; on 2D arrays add axis=0 (per column) or axis=1 (per row).
  • 2D indexing: arr[row, column]; arr[:, 0] is the first column.
  • Broadcasting stretches a number or a row to fit; random numbers come from np.random.default_rng(42).
