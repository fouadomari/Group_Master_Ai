Linear regression: predicting numbers

🎯 Today's goal

By the end of this hour you will:

  • understand a straight line y = a·x + b as a prediction rule
  • see what residuals (the misses) are and why the "best" line makes them small
  • fit a line with NumPy's polyfit and with scikit-learn's LinearRegression
  • measure the errors with MAE, RMSE and R²
  • use several features at once, and know when not to trust a prediction

🤔 Why this matters

Yesterday the model predicted a category (a flower species). That's classification. Today it predicts a number: a price, a temperature, a number of visitors. That's regression.

The simplest regression model is a straight line. If you've ever thought "a bigger flat costs more, about this much per square metre", you already had a linear model in your head. Linear regression finds the line that fits the data best, and it's still one of the most used tools in data science because it's fast and easy to explain.

📏 A line is a prediction rule

A straight line is written as:

price = a × size + b

  • a is the slope: how much the price goes up for each extra m².
  • b is the intercept: where the line starts when the size is 0.

Pick any a and b and you have a model! Let's guess by eye: 2 per m², starting at 60:

Shift + Enter

Not bad, but is it the best line? To answer that, look at the residuals: for each apartment, the real price minus the predicted price. A residual is how much the line missed by. Positive means the line guessed too low, negative too high.

Shift + Enter

.abs() removes the minus signs, so misses in both directions count. Try other values for a and b in the box above and run both boxes again. Can you get the average miss lower?

🎯 Let the computer find the best line

Trying values by hand is slow. The best-fit line is the one that makes the residuals as small as possible (to be exact, it makes the sum of the squared residuals as small as possible, which is why it's also called "least squares"). NumPy finds it in one line. The 1 means "a straight line" (a curve would need a bigger number):

Shift + Enter

Fairly close to the 2.5 and 40 we used to make the data. It isn't exact, because the random noise pushes things around a little. With real data nobody tells you the true numbers, so the fitted line is your best estimate.

📐 How wrong are the predictions?

For numbers, "accuracy" (right or wrong) makes no sense: a prediction of 230 for a real price of 231 isn't "wrong". Instead we measure how far off the predictions are, on the test set:

MeasureWhat it meansGood value
MAE (mean absolute error)the average miss, ignoring the sign, in the same units as the pricesmall
RMSE (root mean squared error)square the misses, average them, take the square root. Like MAE, but big misses count extrasmall
R² ("R squared")how much of the ups and downs in the prices the model explains. 1 = perfect, 0 = no better than always guessing the average priceclose to 1

In words: on apartments it has never seen, the model is off by about 14 thousand on average, and it explains about 92% of the differences in price. model.score(X_test, y_test) gives the same R², just like it gave accuracy for yesterday's classifier. MAE is easy to see by hand, too: it's the mean of the absolute residuals, (y_test - test_predictions).abs().mean().

🚧 Don't trust the line too far

The model only saw apartments between 30 and 120 m². Ask it about sizes far outside that range (extrapolation) and it happily answers, but nothing says the straight line continues out there:

Shift + Enter

An apartment of 0 m² that costs 58 thousand? A 1000 m² palace whose price just follows the same line, although no apartment that big was in the data? A model only knows the world it was trained on. Predict inside the range of your data.

🧩 Several features at once

Real prices depend on more than size (location, age, floor…). Linear regression can use many features: it simply learns one slope for each, and adds them all up: prediction = a1 × feature1 + a2 × feature2 + … + b.

scikit-learn includes a real dataset to try this: load_diabetes. It has 442 patients, 10 features (age, sex, body-mass index bmi, blood pressure bp, and six blood measurements s1–s6) and a label that measures how much the illness progressed one year later (a bigger number = worse).

Teaching example only: we use this medical dataset to practise regression. Nothing here is medical advice. Also, the features have already been rescaled to small numbers around 0, so an "age" of 0.038 doesn't mean a real age.

⚠️ Common mistakes

  • Passing one column with single brackets as X → "Expected a 2-dimensional container". Use df[["col"]].
  • Judging the line on the training data instead of the test set.
  • Using accuracy for numbers. Regression uses MAE, RMSE and R².
  • Trusting predictions far outside the range of the data (extrapolation).
  • Forgetting that coef_ is a list: with one feature, the slope is coef_[0].

✅ Recap

  • A line y = a·x + b is a model: slope a, intercept b.
  • Residual = real value − predicted value. The best-fit line makes the squared residuals as small as possible.
  • np.polyfit(x, y, 1) returns a, b.
  • LinearRegression() → fit → coef_, intercept_, predict, score (R²).
  • MAE = average miss; RMSE punishes big misses; R² = share of the variation explained.
  • More features: same code, a wider X, one slope per feature.
