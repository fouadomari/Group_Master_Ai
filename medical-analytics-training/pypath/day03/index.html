Lists and dictionaries

🎯 Today's goal

By the end of this hour you will:

  • keep many values in one variable with a list
  • pick out items by their position, and cut out pieces of a list with slicing
  • add, insert and remove items, and use sum, min, max and sorted
  • store labelled values in a dictionary, like a price list or a student record
  • combine the two into a tiny table: a list of dictionaries

🤔 Why this matters

Yesterday one variable held one value. But data almost never comes one value at a time: a week has seven temperatures, a class has thirty students, a shop has hundreds of prices.

A list is like a numbered row of boxes: the values stay in order and you find each one by its position. A dictionary is like a real dictionary or a phone book: you look things up by a word (the key) instead of a number. A spreadsheet column is basically a list, and one row of a spreadsheet (column name → value) is basically a dictionary. Later in the course, pandas tables are built from exactly these two ideas.

✂️ Getting several items: slicing

A slice cuts out a piece of a list. You write temps[start:stop]. It starts at start and stops just before stop, so temps[0:3] gives the items at index 0, 1 and 2. Leave out a number to mean "from the very start" or "to the very end":

Shift + Enter

Tip: stop - start is how many items you get. temps[1:6] gives 6 − 1 = 5 items.

⚠️ Common mistakes

  • Counting from 1. The first item is [0] and the last is [-1].
  • Forgetting that a slice stops before the stop number: temps[0:3] is 3 items, not 4.
  • Writing temps = temps.sort(). The list becomes None. Use temps.sort() alone, or sorted(temps).
  • Mixing up brackets: lists use [ ], dictionaries use { }, but you look things up in both with [ ].
  • Misspelling a key, or using a different capital letter ("Apple" is not "apple") → KeyError. Use .get() when a key might be missing.

✅ Recap

  • A list keeps items in order: temps = [21.5, 23.0, 19.8].
  • Indexing starts at 0; -1 is the last item. A slice [start:stop] stops just before stop.
  • .append(), .insert(), .remove(), .pop() change a list; in checks membership.
  • len, sum, min, max, sorted work on whole lists.
  • A dictionary maps keys to values: prices = {"apple": 2.5}. Look up with prices["apple"], add or update with prices["kiwi"] = 3.1, delete with del.
  • .get(key, default) avoids a KeyError; .keys(), .values(), .items() show what's inside.
  • A list of dictionaries is a small table: patients[1]["temp"].
