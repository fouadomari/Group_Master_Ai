Making decisions with if / else

🎯 Today's goal

By the end of this hour you will:

  • ask yes/no questions with comparisons like >, == and !=
  • run code only when something is true, with if and else
  • choose between several options with elif, for example grade bands
  • combine questions with and, or and not
  • know why indentation (spaces at the start of a line) matters in Python

🤔 Why this matters

Until now Python ran every line, every time, from top to bottom. Real programs need to choose. A thermometer app shows a warning only if you have a fever. A shop gives a discount only if you are a student.

Think of a fork in a road with a sign: "if it's raining, take the left path, otherwise take the right." In data work, decisions are everywhere: labelling a temperature as cold, mild or hot, flagging a strange value as an error, or putting customers into groups. Even a machine learning model, in the end, makes a decision like "spam or not spam".

Remember: the code boxes on this page share their variables, like pages of one notebook. Run them from top to bottom. If you see a NameError, you probably skipped a box above.

🐞 The = vs == mistake

Writing one equals sign inside an if means "store", which makes no sense as a question. Python stops before running anything, with a SyntaxError, and even guesses what you meant:

🫙 Empty means False

A small but handy fact: in an if, an empty list [], empty text "" and the number 0 count as False. Anything else counts as True. So if queue: reads as "if the queue has anyone in it":

⚠️ Common mistakes

  • Using = instead of == in a condition → SyntaxError.
  • Forgetting the colon : at the end of the if, elif or else line.
  • Missing or uneven indentation → IndentationError. Use 4 spaces for every level.
  • Putting elif bands in the wrong order, so an early band catches everything.
  • Writing if x == 1 or 2:. It's always true! Write if x == 1 or x == 2: (or if x in [1, 2]:).

✅ Recap

  • Comparisons == != < > <= >= give True or False.
  • if condition: runs the indented block only when the condition is true.
  • else: is the other path; elif condition: adds more paths. Only the first true one runs.
  • and needs both, or needs at least one, not flips.
  • in works inside conditions: if medicine in allergies:
  • Indentation (4 spaces) shows which lines belong to which block.
  • Empty lists, empty text and 0 count as False.
