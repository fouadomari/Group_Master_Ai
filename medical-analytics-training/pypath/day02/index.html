Variables and data types

🎯 Today's goal

🤔 Why this matters

Yesterday every number disappeared as soon as Python printed it. Real data work needs Python to remember things: a price, a temperature, a customer's name.

A variable is like a labelled box: you put a value inside and write a name on the label. Later you ask for the box by its name. In a spreadsheet, the column names (age, city, salary) play the same role — and data types decide whether a column holds numbers you can add up or text you can't.

🏷️ Naming your variables

Python has a few rules for names:

  • Use letters, numbers and the underscore _. No spaces.
  • A name can't start with a number: 2nd_place is not allowed, second_place is.
  • Capital letters matter: Age and age are two different variables.

Python programmers write names in snake_case: all lowercase, with underscores between words, like monthly_salary or average_temperature. Choose names that say what's inside — total_price is much clearer than tp or x.

🧱 Data types

⚠️ Common mistakes

  • Reading = as "equals". It means "store in". (Comparing uses ==, coming on Day 4.)
  • Using a variable before creating it, or with a typo → NameError.
  • Putting quotes around a variable name: print("city") prints the word city, print(city) prints what's inside.
  • Doing maths with numbers stored as text: "5" + 3 → convert first with int() or float().
  • Forgetting the f in an f-string: "{name}" prints the curly brackets literally.

✅ Recap

  • name = value stores a value in a variable; use the name to get it back.
  • +=, -=, *=, /= update a variable based on its old value.
  • Names: lowercase snake_case, no spaces, can't start with a number.
  • Four basic types: int, float, str, bool. Check with type().
  • Convert with int(), float(), str(); round with round().
  • f-strings: f"{name} is {age}", and {value:.2f} for 2 decimals.
