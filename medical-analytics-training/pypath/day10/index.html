🤔 Why this matters

pandas is the most used data tool in Python. If NumPy is a calculator for grids of numbers, pandas is a spreadsheet you control with code: its tables have column names, can mix numbers, text and dates, and come with hundreds of ready-made tools.

The first thing a data scientist does with any new dataset is exactly today's topic: load it and look at it. How many rows? What columns? Which types? Any strange values? You can't analyse data you haven't looked at.

Remember: the code boxes on this page share their variables, like pages of one notebook. Run them from top to bottom. The first box downloads pandas, so it can take 10 to 20 seconds the first time.

📍 Picking rows and cells: .loc and .iloc

.loc[rows, columns] picks by label (index labels and column names). .iloc[rows, columns] picks by position (0, 1, 2, …, like a list). Here the row labels happen to be 0, 1, 2…, so they look alike, but on Day 11 you'll see when they differ:

Shift + Enter

Watch out: a slice with .loc includes the end label (0:2 gives 3 rows), while .iloc works like a normal Python slice and excludes the end (0:2 gives 2 rows).

🔢 Counting values

For text columns, the most useful question is "how often does each value appear?". value_counts() answers it, sorted from most to least common. unique() lists the different values and nunique() counts them:

Shift + Enter

value_counts() returns a Series: the drinks are its index and the counts its values. So sales["drink"].value_counts()["tea"] gives the number of tea orders, and .index[0] gives the most common drink.

➕ Adding a column

Columns work like NumPy arrays: maths happens on every row at once. Assigning to a new column name adds the column:

pandas 3 rule: to change a value, always use .loc[row, column] = value. The look-alike sales["qty"][0] = 2 (two pairs of brackets one after the other) changes a temporary copy and leaves your table unchanged. This behaviour is called copy-on-write.

⚠️ Common mistakes

  • Misspelling a column name (capitals matter) → KeyError. Check df.columns.
  • Single vs double brackets: df["a"] is a Series, df[["a", "b"]] is a DataFrame.
  • Forgetting that .loc slices include the end, while .iloc slices don't.
  • Changing a value with df["col"][0] = …: in pandas 3 this does nothing. Use df.loc[0, "col"] = ….
  • Writing df.shape() with brackets: shape and columns are not functions, head() and describe() are.

✅ Recap

  • import pandas as pd; a Series is one labelled column, a DataFrame is a table.
  • pd.DataFrame({...}) from a dict; pd.read_csv(...) from a file (here via io.StringIO).
  • Inspect with head(), tail(), shape, columns, dtypes, info(), describe().
  • df["col"], df[["a", "b"]], df.loc[label, "col"], df.iloc[row, col].
  • value_counts(), unique(), nunique() for counting.
  • df["new"] = df["a"] * df["b"] adds a column; sort_values("col", ascending=False) sorts; to_csv(name, index=False) saves.
