Repeating work with loops

🎯 Today's goal

By the end of this hour you will:

  • repeat code for every item in a list with a for loop

  • build a new list, step by step, with .append()
  • use range(), enumerate() and loop over a dictionary
  • repeat while something is true with a while loop, and stop early with break

🤔 Why this matters

Imagine checking a list of 10 000 temperatures for fevers by writing 10 000 if lines. Nobody does that. Instead you write the check once and tell Python: "do this for every value in the list." That's a loop.

It's like a cashier scanning a basket: pick up an item, scan it, add its price to the total, pick up the next item… until the basket is empty. Computers are brilliant at this kind of boring repetition, and almost every piece of data analysis is a loop underneath, even when a library like pandas hides it from you.

⏳ The while loop

A for loop runs once per item. A while loop runs as long as a condition is true, like an if that keeps repeating. It's useful when you don't know in advance how many rounds you need. How many months does it take to save 1000 dollars, putting away 150 a month?

Endless loops. If nothing inside a while loop ever makes its condition False, it runs forever. On this page Python stops your code after 20 seconds with a TimeLimitExceeded message (and the page freezes until then). If you see it, look for the line that should change the condition, like count -= 1.

🛑 Stopping early: break and continue

break leaves the loop immediately. It's perfect for "find the first one": once you've found it, there's no need to look further. continue skips the rest of this round and jumps to the next item.

⚠️ Common mistakes

  • Starting the accumulator inside the loop (total = 0 under the for): it's reset every round. Put it before the loop.
  • Indenting a line that should run once after the loop (like the final print), so it runs every round.
  • Forgetting the colon at the end of the for or while line.
  • A while loop whose condition never becomes False → it's stopped after 20 seconds.
  • for i in 5: → TypeError. Use range(5).
  • Forgetting that range(1, 10) stops at 9.

✅ Recap

  • for item in my_list: runs the indented block once for each item.
  • Accumulator: total = 0 before the loop, total += x inside. Counter: count += 1 inside an if.
  • New list: result = [] before, result.append(...) inside.
  • range(start, stop, step) makes a series of numbers, stopping before stop.
  • enumerate() gives index and item; .items() gives key and value.
  • while condition: repeats as long as the condition is true.
  • break leaves the loop; continue jumps to the next round.
  • [x * 2 for x in nums if x > 1] builds a list in one line.
