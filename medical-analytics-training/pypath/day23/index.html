🤔 Why this matters

Welcome to deep learning, the part of machine learning behind face unlock on phones, voice assistants, translation apps and chatbots. Its models are called neural networks: many tiny calculators called neurons, connected in layers. "Deep" just means "many layers".

The name comes from the brain. A brain cell receives signals from other cells, and if the signals together are strong enough, it "fires" and passes a signal on. An artificial neuron is a very simplified copy of that idea, made of nothing more than multiplication, addition and one small function. Over the last few days scikit-learn did the learning for you with .fit(). Today you'll build the smallest piece yourself and watch it learn.

🧠 Inputs, weights and a bias

Imagine a neuron that decides "Should I go to the beach today?". It looks at three yes/no facts (1 = yes, 0 = no). These made-up facts are its inputs:

  • Is it sunny? Is it warm? Is a friend coming?

Not every fact matters equally. Each input gets a weight: a number that says how important it is, like a volume knob for that input. A big weight means "this matters a lot"; a negative weight means "this speaks against going". Finally, the bias is a starting push that is added no matter what. A negative bias means "I'm a bit lazy: I need good reasons before I say yes".

The neuron multiplies each input by its weight, adds everything up, and adds the bias. The result is called the weighted sum, usually written z:

z = input1 × weight1 + input2 × weight2 + input3 × weight3 + bias

⚡ From a number to a decision: activation

z = 2.5 is just a number. To turn it into an answer, the neuron passes it through an activation function. It decides how strongly the neuron "fires". The simplest one is the step function: if z is above 0, answer 1 (yes), otherwise 0 (no).

Shift + Enter

The step function is very blunt: z = 0.01 and z = 500 both give 1. The sigmoid function is gentler. It squashes any number into a value between 0 and 1, which we can read as "how sure" the neuron is. Big negative z → close to 0, big positive → close to 1, and z = 0 → exactly 0.5 (can't decide). It uses np.exp, the "e to the power of" function from maths:

sigmoid(z) = 1 / (1 + e−z). You don't need to remember the formula, only its S-shape.

🎓 Letting the neuron learn: the perceptron rule

Picking weights by hand is fine for 2 inputs, impossible for 1000. So let the neuron find them itself. A neuron with a step activation is called a perceptron (invented in 1958), and it learns like someone adjusting a shower: too cold → turn a little warmer, too hot → a little colder, just right → leave it.

  1. Start with all weights and the bias at 0 (it knows nothing).
  2. For each example: make a prediction and compute the error = wanted − predicted. It is +1 ("you should have said yes"), −1 ("you should have said no") or 0 (correct).
  3. Nudge each weight: w += learning_rate × error × input, and the bias: b += learning_rate × error. Inputs that were 0 didn't cause the mistake, so their weights don't change.
  4. Repeat for all examples, many times.

Two new words:

  • Learning rate (lr): how big each nudge is. Small = careful, slow steps.
  • Epoch: one full pass through all the training examples. Training usually takes many epochs.

❌ The problem one neuron can't solve: XOR

XOR means "exactly one of the two". It sounds just as easy as OR. Let's give the perceptron 1000 epochs:

It never gets all four right. The picture shows why:

Shift + Enter

The green points sit on one diagonal and the red points on the other. Try to imagine one straight line with all greens on one side and all reds on the other: it can't be done. And one neuron can only draw one straight line.

The fix: use several neurons in a row. A first layer of neurons draws a few lines, and a second layer combines their answers. That's a neural network, and you'll build one that solves XOR tomorrow. (In 1969 a famous book pointed out this XOR limit, and interest in neural networks dropped for years until layered networks became trainable.)

⚠️ Common mistakes

  • Forgetting the bias. Without it, the neuron's line must pass through (0, 0), and a gate like AND becomes impossible.
  • Shape mismatch in X @ w: the number of columns of X must equal the number of weights. Print the .shapes.
  • Writing np.exp(z) instead of np.exp(-z) in the sigmoid: big z then gives values near 0 instead of 1.
  • Using = instead of += in the learning rule: the weights forget everything they learned before.
  • Expecting one neuron to learn anything. It can only separate data with one straight line.

✅ Recap

  • A neuron computes z = inputs · weights + bias, then an activation: output = activation(z).
  • Weights say how much each input matters; the bias is a starting push.
  • np.dot(x, w) or x @ w is the weighted sum; X @ w does it for every row of X.
  • Step gives 0 or 1; sigmoid 1 / (1 + np.exp(-z)) gives a smooth value between 0 and 1.
  • The perceptron rule: w += lr × error × x, b += lr × error, repeated for many epochs.
  • One neuron draws one straight line, so it can learn AND and OR but not XOR. That's why networks have layers.
