🤔 Why this matters

So far all your data lived inside the code. Real data lives in files: a spreadsheet exported as CSV, a log of sensor readings, a list of customers. Today you'll learn to save data to a file and load it again.

Real data is also messy. One sensor writes "oops" instead of a number, a file is missing, a shop had zero visitors. Without care, one bad value crashes your whole program. try / except is like a safety net under a tightrope walker: if something goes wrong, you catch it and decide what to do.

And you don't have to build everything yourself. Python comes with a big toolbox of modules. Data scientists use them all day: NumPy and pandas (coming on Days 9 and 10) are modules too.

Remember: the code boxes on this page share their variables, like pages of one notebook. Run them from top to bottom. If you see a NameError, you probably skipped a box above.

🧰 Modules: Python's toolbox

A module is a file full of ready-made functions and values that someone else wrote. To use one, you import it. Then you write the module's name, a dot, and the tool you want. The math module has maths tools that the basic operators don't:

The statistics module calculates averages for you. Its name is long, so we give it a nickname with as. You'll see this a lot: on Day 9 you'll write import numpy as np.

Two kinds of "average" are worth knowing. The mean adds everything up and divides by how many there are. The median is the middle value after sorting. One extreme value pulls the mean a lot, but barely moves the median:

The mean says "about 24 minutes", but most patients waited 9 to 15. The median (13) describes a typical patient much better.

The random module makes random numbers, which is handy for creating made-up data or picking a random sample. Computers make "random" numbers from a starting number called a seed. Fix the seed with random.seed(42) and you get the same numbers every time you run the box, so your results can be repeated:

📝 Writing a text file

open("diary.txt", "w") opens a file for writing (it creates the file, or empties it if it already exists). The with line means "use this file for the indented lines below, then close it properly". f is just a short name for the open file.

Shift + Enter

\n means "new line". write() doesn't start a new line by itself, so we add \n at the end of each line.

Where is the file? On this page, Python runs inside your browser, so files are kept in the page's memory, not on your computer's disk. They disappear when you reload the page. On your own computer, the same code creates a real file next to your program.

📊 Tables in CSV files

CSV stands for "comma-separated values". It's the simplest way to store a table: one row per line, with commas between the columns. Every spreadsheet program can open and save CSV files. The csv module writes and reads them for you:

newline="" is a small detail the csv module asks for, so it can handle line endings itself. Just always add it when you open a CSV file.

csv.reader reads the file back, one row (a list) at a time. next(reader) takes the next row out, which is a neat way to grab the header row before the loop:

🚨 Raising your own errors

Sometimes you know a value is wrong, even though Python wouldn't complain: a negative price, an age of 250. You can stop with a clear message using raise. And except ValueError as err catches the error and keeps its message in the variable err, so you can print it:

⚠️ Common mistakes

  • Forgetting to import a module before using it → NameError: name 'math' is not defined.
  • Opening a file with "w" when you meant to read or add: "w" empties it first!
  • Forgetting \n when writing lines: everything ends up on one long line.
  • Doing maths with values read from a file without converting them: they are always text.
  • Wrong indentation after with, try or except: the lines that belong to them must be indented.
  • Using a bare except: that hides every error, including your own typos.

✅ Recap

  • import math, from math import pi, import statistics as st: three ways to use a module.
  • math (sqrt, pi, ceil, floor), statistics (mean, median), random (seed, randint, choice).
  • with open(name, "w") as f: then f.write(...); read with f.read(), f.readlines() or for line in f.
  • csv.writer(f).writerows(rows) saves a table; csv.reader(f) reads it back as lists of text.
  • try / except ErrorName catches an error; else runs if all went well; finally always runs.
  • raise ValueError("message") stops with your own clear message.
