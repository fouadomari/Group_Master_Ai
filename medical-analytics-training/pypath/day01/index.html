📐 Order of operations

Python follows the same rules you learned at school: brackets first, then powers, then multiply/divide, then add/subtract.

Shift + Enter

See the # symbols? Everything after a # is a comment. Python ignores comments — they are notes for humans. Good programmers use them to explain why they did something.

🐞 Errors are your friends

Everyone — even experts — gets errors every day. An error is just Python saying "I don't understand this line". It tells you which line and what kind of problem. This box has a missing closing quote on purpose:

Shift + Enter

Python reports a SyntaxError: the code isn't written in a form Python can read. Here's another common one — mixing text and numbers:

Shift + Enter

A TypeError means you tried to combine things that don't fit together. Fix it with commas instead: print("I am", 25, "years old").

How to read an error: look at the last line first. It names the error type and gives a short explanation. Then look at the line number above it.

⚠️ Common mistakes

  • Forgetting quotes around text: print(Hello) → Python thinks Hello is a name it should already know.
  • Mismatched quotes: print("Hi') → the start and end quotes must be the same kind.
  • Capital letters: Print("Hi") doesn't work. Python is case-sensitive: print ≠ Print.
  • Forgetting the brackets: print "Hi" was old Python 2 style and no longer works.

✅ Recap

  • print(...) shows things on the screen.
  • Text goes in quotes (a string); numbers don't.
  • + - * / // % ** do maths; brackets control the order.
  • # starts a comment.
  • Errors are normal: read the last line first.
