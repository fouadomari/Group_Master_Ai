⚠️ Common mistakes

  • Running the "add" box several times and adding the same expense again and again.
  • Forgetting that values loaded from a CSV file are text: convert amounts with float().
  • A function that prints its result instead of returning it: then you can't use the result in another function.
  • Misspelling a dictionary key: e["ammount"] gives a KeyError.
  • Checking data too late: validate it when it arrives, in one place (add_expense).

✅ Recap

  • A list of dictionaries works like a table: one dictionary per row, keys as column names.
  • Validate input and raise ValueError with a clear message; catch it with try / except.
  • "Group and add up": totals[key] = totals.get(key, 0) + value.
  • text.startswith("2026-03") picks out one month from dates written as text.
  • Save with csv.writer, load with csv.reader + float() + FileNotFoundError.
  • Line up columns with {text:<12} and {number:>8.2f}.
