🤔 Why this matters

Reading handwriting was one of the first big jobs for neural networks: in the 1990s, banks and post offices used them to read cheques and postcodes. Today the same idea, scaled up, lets your phone recognise faces and lets cars spot road signs.

Yesterday you built a network by hand for 4 examples. Today you'll use a ready-made one from scikit-learn on almost 1800 small pictures. Under the hood it does exactly what you wrote yesterday: forward pass, loss, backpropagation, gradient descent.

🖼️ A picture is just numbers

scikit-learn comes with a small dataset of handwritten digits (0 to 9), collected from real people's handwriting in the 1990s. It is built into the library, so nothing is downloaded. Each picture is tiny: 8 × 8 pixels. Each pixel (one dot of the picture) is a number from 0 (white) to 16 (black).

📏 From a grid to 64 features

The models you know expect each example as one row of features, like a row in a table. So we flatten each 8 × 8 grid into one row of 64 numbers: row 1 of the picture, then row 2, and so on. .reshape(64) does that, and the dataset already has the flat version ready in digits.data:

Shift + Enter

One more step: scaling. Neural networks learn best when the inputs are small, roughly between 0 and 1 (remember yesterday: big inputs make big gradient steps, and the learning can jump around). Dividing by 16 turns 0–16 into 0–1. Then we split into training and test sets as on Day 16, keeping the same mix of digits in both (stratify=y):

🧠 A neural network that reads digits

scikit-learn's MLPClassifier is a ready-made neural network. MLP stands for multi-layer perceptron: layers of neurons, just like yesterday. Ours will have:

  • 64 inputs: one per pixel.
  • One hidden layer of 64 neurons: hidden_layer_sizes=(64,). (Two hidden layers would be (64, 32).)
  • 10 outputs: one per digit. The biggest one wins.

A few things are different from our hand-made network, but the idea is the same:

WordWhat it means
ReLUThe hidden neurons' activation: z if it's positive, otherwise 0. Simpler than sigmoid and learns faster in big networks.
softmaxTurns the 10 output scores into 10 probabilities that add up to 1.
adamThe optimiser: gradient descent that adjusts its own step size for each weight.
mini-batchEach step uses a small batch of 200 pictures instead of all of them, so steps are quick.
max_iterThe number of epochs (passes through the training data).

📊 How sure is the network?

predict_proba gives the 10 probabilities (from softmax) for each picture. The biggest one is the network's confidence in its answer. .max(axis=1) takes the biggest number in each row. Is the network less sure when it's wrong?

Shift + Enter

On average the network is clearly less sure when it's wrong, and for its shakiest mistake the probability is spread over several digits. But not always: a few mistakes are made with high confidence. In real systems, pictures with low confidence are often sent to a human to check.

⚖️ Is the network worth it?

Always compare with a simpler model (Day 20's checklist). Logistic regression (Day 18) is like a network with no hidden layer:

Shift + Enter

The hidden layer helps, but the simple model is already good on these tiny, clean pictures. On big photos, networks with many layers win by a huge margin. Also notice the network's train accuracy (almost 100%) is higher than its test accuracy: it remembers its training pictures a bit too well. That gap is tomorrow's topic.

⚠️ Common mistakes

  • Forgetting to scale the pixels (/ 16): the network learns slower and worse.
  • Passing one picture as a 1D row → ValueError: Expected 2D array. Use .reshape(1, 64).
  • Passing digits.images (8 × 8 grids) to the model instead of digits.data (flat rows of 64).
  • Judging the model on its training pictures. Only the test accuracy tells you how it does on new handwriting.
  • Forgetting random_state=42: the network starts from random weights, so results change a little each run.

✅ Recap

  • A greyscale picture is a grid of numbers; plt.imshow(image, cmap="gray_r") shows it.
  • Flatten 8 × 8 into 64 features (.reshape(64) or digits.data) and scale to 0–1.
  • MLPClassifier(hidden_layer_sizes=(64,), max_iter=200, random_state=42), then .fit, .score, .predict.
  • The confusion matrix shows which digits get mixed up; looking at the mistakes shows why.
  • predict_proba tells you how confident the network is.
  • Always compare with a simpler model.
