🎲 Why isn't it 95%?

Look again at the generator: survival was decided by rng.random(n) < chance, a dice roll. A woman in 1st class had a high chance, not a certain one. No model can predict dice. Because we made the data, we can calculate the best possible accuracy: always guess the more likely outcome for each passenger, using the true chance values from Step 1:

So about 0.74 is the ceiling, and our models reach around 0.7 in cross-validation: close to perfect for this problem. Real data is like this too: there is always some randomness no model can explain. A "low" score isn't always a bad model.

⚖️ Limits and fairness

  • Made-up data: these predictions describe our invented ship, not real people or real ships.
  • Small data: 400 passengers is tiny. Scores move a lot between splits; cross-validation helps.
  • Luck: some outcomes are random. The model gives a probability, not a promise.
  • Fairness: the model leans heavily on sex and class. That describes who was helped in the (made-up) past; it is not a rule for how people should be treated. When models are used for real decisions (loans, jobs, medicine), using features like sex, or features linked to wealth, can repeat old unfairness. Always ask who could be harmed by a model's mistakes.

⚠️ Common mistakes

  • Leaving missing values or text columns in X. Clean and encode first.
  • Encoding categories like ports as 0, 1, 2. Use one-hot columns (pd.get_dummies) instead.
  • Keeping ID columns or the label itself in X.
  • Skipping the baseline: 60% accuracy sounds fine until you see that "always no" gets 59%.
  • Preparing new data differently from training data → column errors or silent wrong answers.
  • Trusting one small test set. Confirm with cross-validation.

✅ Recap: the full recipe

  1. Clean: drop_duplicates(), fillna(median).
  2. Features: .map({...}) for two values, pd.get_dummies for categories; drop IDs.
  3. Split: train_test_split(..., stratify=y, random_state=42).
  4. Baseline: DummyClassifier(strategy="most_frequent").
  5. Models: scaled logistic regression, random forest with limited depth.
  6. Evaluate: confusion matrix, precision, recall, cross_val_score.
  7. Predict: prepare new rows the same way, then predict_proba.
